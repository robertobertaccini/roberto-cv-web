# Roberto Bertaccini - Interactive CV

This is an interactive, web-based version of Roberto Bertaccini's Curriculum Vitae.

## Features
- **Responsive Design**: Built with Tailwind CSS.
- **Dark Mode**: Toggle between light and dark themes.
- **Interactive Tabs**: Easily navigate through different work experiences.
- **Modern Stack**: HTML5, Tailwind CSS (via CDN), Vanilla JavaScript.

## How to view
Simply open `index.html` in any modern web browser.
